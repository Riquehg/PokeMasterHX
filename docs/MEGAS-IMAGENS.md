# 💎 Imagens das Megas — lista de arquivos

Tudo vai no bucket **sprites** do Supabase Storage (o mesmo dos outros sprites). Nomes em minúsculas, `.png`, no padrão do Pokémon Showdown.
Se faltar alguma imagem, o jogo mostra o sprite da forma normal com um brilho arco-íris (não quebra nada).

68 Megas: as 48 clássicas (X/Y e ORAS) + 20 de Pokémon Legends: Z-A.
Ficaram de fora (a espécie base não existe no jogo, que vai até a Gen 7): **Crucibelle** (é um Pokémon fã-feito do Smogon), **Glimmora** e **Scovillain** (Gen 9). O arquivo `meganium.png` (sem `-mega`) não é usado.
